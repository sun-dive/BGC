# bitgraf.com — Bit Graf Corporation (BGC)

Corporate placeholder landing for **bitgraf.com** — the asset exchange / on-chain rail beneath the **grafverse** world (where players paint worlds into existence and own what they make).

Single self-contained `index.html`: no build step, no external assets. Premium-dark corporate look, the masonic **Y-seam cube** mark, and the ownership ethos in the fine print ("All rights reserved — to their creators").

## Deploy (cPanel Git)
1. Push to the `sun-dive/BGC` GitHub repo.
2. cPanel → Git Version Control → **Update from Remote** → **Deploy HEAD Commit**.
3. `.cpanel.yml` copies `index.html` to `$HOME/bitgraf.com/`.

Part of the grafverse / bitgraf universe. *You are what you paint. Paint what you are.*
